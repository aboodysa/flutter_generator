FAHS Prototype V2 — مطابق أكثر للـ Figma / Flutter

تم تحديث البروتوتايب بناءً على الصور الجديدة: ألوان #7237E9 / #EFE9FB / #F7F7F7، خط Tajawal، iPhone frame، dynamic island، bottom nav، كروت قريبة من التصميم، شاشات العميل ومقدم الخدمة، ونسخ حالات bottom sheet / payment / report / wallet / orders.

Variance fixes applied in V2

  • استبدال primary إلى Blue‑Violet #7237E9 بدل الدرجة القديمة.
  • اعتماد Lavender #EFE9FB و Gray #F7F7F7 و Cultured #F5F5F5.
  • تغيير الخط إلى Tajawal بأوزان Regular / Medium / Bold.
  • تصغير الـ radii في الحقول والكروت لتقارب صور Figma.
  • إعادة بناء bottom navigation بأيقونات خطية ونصوص صغيرة.
  • إضافة splash مطابق أكثر: خلفية لافندر، خطوط دائرية، شعار، سيارة.
  • إضافة auth screens مع keyboard mock ورقم/OTP كما في الصور.
  • إضافة تفاصيل نقل الملكية، فحص السيارة، الدفع، الصور، التقرير.
  • إضافة provider orders, accept/cancel sheets, services, wallet, employees.
  • إضافة design-system board للألوان والخط والأيقونات والمكونات.
